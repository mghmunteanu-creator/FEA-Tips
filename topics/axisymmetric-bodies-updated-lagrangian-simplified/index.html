01

Introduction

Section 28.4 presented a direct and consistent Updated Lagrangian (UL) formulation for axisymmetric four-node isoparametric elements. Although mathematically rigorous, the derivation of the tangent stiffness matrix is relatively involved, particularly because of the circumferential contributions and the variation of the axisymmetric integration measure.

A simpler alternative is presented here.

The basic idea is to apply the Total Lagrangian (TL) formulation at each load step, taking the configuration obtained at the end of the preceding step as the reference configuration for the next increment. Consequently, most of the element calculations developed in Section 28.3 can be reused, with relatively few modifications.

The main differences concern the updating of the reference geometry and the accumulation and transformation of the strain components.

The method is easier to implement than the direct consistent UL formulation. However, it employs an approximate incremental tangent and its numerical results may depend on the number of load steps.

The same axisymmetric Q4 element, isotropic elastic material and one-radian integration convention are adopted.

02

Incremental formulation

2.1. Updating the reference configuration

Consider the equilibrium configuration reached at the end of load step nnn. The nodal coordinates of this configuration are

xn\boldsymbol{x}_nxn​

and are used as the reference coordinates for the next load increment. The displacement increment is

Δun+1\Delta\boldsymbol{u}_{n+1}Δun+1​

At the end of the new load step, the geometry is updated according to

xn+1=xn+Δun+1\boldsymbol{x}_{n+1}=\boldsymbol{x}_n+\Delta\boldsymbol{u}_{n+1}xn+1​=xn​+Δun+1​

The total displacement vector, measured from the initial configuration, is accumulated as

un+1=un+Δun+1\boldsymbol{u}_{n+1}=\boldsymbol{u}_n+\Delta\boldsymbol{u}_{n+1}un+1​=un​+Δun+1​

Within each load step, the element stiffness and internal forces are evaluated using the TL-type expressions associated with the reference configuration at the beginning of that step. Thus, the procedure requires no complete rederivation of the TL element matrices presented in Section 28.3.

2.2. Incremental strains

At each Gauss point, the incremental Green–Lagrange strain tensor is calculated from the displacement increment relative to the preceding equilibrium configuration:

ΔE=12(FΔTFΔ−I)\Delta\boldsymbol{E}=\frac12\left(\boldsymbol{F}_\Delta^T\boldsymbol{F}_\Delta-\boldsymbol{I}\right)ΔE=21​(FΔT​FΔ​−I)

where FΔ\boldsymbol{F}_\DeltaFΔ​ is the incremental deformation gradient. For axisymmetric deformation, with radial displacement increment Δu\Delta uΔu and axial displacement increment Δv\Delta vΔv,

FΔ=[1+Δu,rΔu,y0Δv,r1+Δv,y0001+Δu/r]\boldsymbol{F}_\Delta=\begin{bmatrix}1+\Delta u_{,r}&\Delta u_{,y}&0\\\Delta v_{,r}&1+\Delta v_{,y}&0\\0&0&1+\Delta u/r\end{bmatrix}FΔ​=​1+Δu,r​Δv,r​0​Δu,y​1+Δv,y​0​001+Δu/r​​

Here, rrr is the radial coordinate in the reference configuration of the current load step. The incremental strain components are obtained using the same expressions as in Section 28.3, but with the incremental displacements and the updated reference geometry.

2.3. Accumulation and correction of strains

The essential feature of the method is the accumulation of the strain components from successive load steps. Let en\boldsymbol{e}_nen​ denote the accumulated Euler–Almansi strain tensor at the end of the preceding step. At the current trial configuration, the accumulated strain is corrected using the incremental deformation gradient:

en+1=FΔ−T(en+ΔE)FΔ−1\boldsymbol{e}_{n+1}=\boldsymbol{F}_\Delta^{-T}\left(\boldsymbol{e}_n+\Delta\boldsymbol{E}\right)\boldsymbol{F}_\Delta^{-1}en+1​=FΔ−T​(en​+ΔE)FΔ−1​

This expression accounts for both the incremental deformation and the transformation of the previously accumulated strain to the new configuration. In the MATLAB program, the correction is implemented by the following operations:

FF=[1+ux uy 0; vx 1+vy 0; 0 0 1+ug/r];
FF=inv(FF);
ee=[ex exy/2 0; exy/2 ey 0; 0 0 ez];
ee=FF'*ee*FF;
ex =ee(1,1);
ey =ee(2,2);
ez =ee(3,3);
exy=2*ee(1,2);

Before this correction, the incremental Green–Lagrange strain components have been added to the accumulated components from the preceding load step. The corrected strains are used to calculate the stresses through the axisymmetric Hooke matrix presented in Section 28.1.

Unlike the direct formulation in Section 28.4, the tangent stiffness matrix is not obtained by consistently differentiating the complete expression for the updated internal forces. The method therefore provides a simpler, but approximate, incremental algorithm.

It is important to note that even with a single load step, the strain correction remains active. Thus, the method does not necessarily reproduce exactly the numerical result of the TL formulation in Section 28.3.

03

MATLAB implementation

The MATLAB implementation is based on the programs developed for the TL formulation in Section 28.3. Only the essential modifications are described here.

In main.m, the displacement vector associated with the current increment is initialized at the beginning of each load step:

for istep=1:nstep
    S=zeros(neq,1);

After convergence, the current nodal coordinates and total displacements are updated:

x=x+S(1:2:neq);
y=y+S(2:2:neq);
St(:,istep+1)=St(:,istep)+S;

In stiff.m, the incremental strains are calculated using the current step’s reference configuration, added to the previously accumulated strains and transformed according to the relationship developed in §02.3.

The element stiffness retains the TL-type material and geometric contributions, while the axisymmetric integration factor is

rdet⁡(J)r\det(\boldsymbol{J})rdet(J)

corresponding to a circumferential sector of one radian.

The programs plot_disp.m and plot_stress.m provide graphical representations of the displacement and stress distributions. The complete MATLAB package can be downloaded below.

Numerical example and comparison

We reconsider the toroidal container subjected to prescribed nodal forces, as presented in Section 28.3 and Section 28.4. The geometry, material parameters, boundary conditions and final loading are unchanged.

The purpose of this comparison is to examine the influence of the number of load steps on the simplified incremental formulation and to compare its results with those obtained using the direct consistent UL method.

The difference in the maximum axial displacement is only 0.015 mm, corresponding to approximately 0.059% of the direct consistent UL result. The radial displacement extrema are even closer. Thus, despite its approximate incremental character, the simplified formulation provides very satisfactory results when sufficiently small load increments are used.

The direct consistent approach, on the other hand, gives the same final displacement extrema to the reported numerical precision when different numbers of load steps are employed, provided the calculations converge to the same equilibrium solution.

05

Final remarks

The simplified incremental approach extends the TL implementation of Section 28.3 by updating the reference geometry after each load step and accumulating the strains in the current configuration. Its principal advantage is the ease of implementation, since most of the TL element calculations can be retained. Its main limitation is the dependence of the numerical solution on the load-step size.

For the toroidal example considered here, the displacement results approach those of the direct consistent UL formulation as the number of load steps increases, with very small differences already observed for 20 steps.

The simplified formulation therefore offers an accessible alternative for studying axisymmetric geometrically nonlinear problems, while the direct consistent formulation of Section 28.4 provides a more rigorous treatment of the tangent stiffness matrix.

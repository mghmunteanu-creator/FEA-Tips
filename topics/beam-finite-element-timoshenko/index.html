01

Model and kinematics

The straight, prismatic two-node element is analysed in the global xyxyxy plane. Small strains, small displacements, and linear elastic material behaviour are assumed.

Each node has the local degrees of freedom uˉ\bar uuˉ, vˉ\bar vvˉ, and ψ\psiψ. The local element vector is

uˉel={uˉ1,vˉ1,ψ1,uˉ2,vˉ2,ψ2}T\bar{\boldsymbol u}_{el}=\left\{\bar u_1,\bar v_1,\psi_1,\bar u_2,\bar v_2,\psi_2\right\}^{T}uˉel​={uˉ1​,vˉ1​,ψ1​,uˉ2​,vˉ2​,ψ2​}T

The rotation of the normal and the rotation of the cross-section are different quantities:

φ=dvˉdxˉ,ψ=rotation of the cross-section,β=φ−ψ\varphi=\frac{d\bar v}{d\bar x},\qquad \psi=\text{rotation of the cross-section},\qquad \beta=\varphi-\psiφ=dxˉdvˉ​,ψ=rotation of the cross-section,β=φ−ψ

Thus β\betaβ is the shear angle. The Euler–Bernoulli model is recovered when β=0\beta=0β=0, so that φ=ψ\varphi=\psiφ=ψ.

07

MATLAB programs

The package contains five commented files. gen.m defines the model; deriv.m evaluates the generalized strain rows; stiff.m uses two-point Gauss integration and assembles the structure; stress.m recovers N, T, and M; and main.m runs the analysis and plots the results.

stiff.mTwo-point Gauss integration
%*** stiff.m ***
for ig = 1:2
    xc = 1/2*(1 + xg(ig));
    deriv
    kel = kel + L/2*(ea*ep1*ep1' + ga*be1*be1' + ei*ka1*ka1');
end
K(ip,ip) = K(ip,ip) + R'*kel*R;
MATLAB compatibility

The package uses MATLAB R2017b-compatible syntax and was checked with MATLAB R2026a. No additional toolbox is required.

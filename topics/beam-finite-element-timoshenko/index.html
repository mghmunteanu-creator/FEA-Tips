01

Model and kinematics

A straight, prismatic two-node beam element of constant cross-section is analysed in the global xyxyxy plane. Small strains, small displacements, and linear elastic material behaviour are assumed [1].

The local xˉ\bar xxˉ axis coincides with the neutral axis of the element, while yˉ\bar yyˉ​ is a principal axis of the cross-section. The angle θ\thetaθ defines the orientation of the local frame with respect to the global frame.

Each node has the local degrees of freedom uˉ\bar uuˉ, vˉ\bar vvˉ, and ψ\psiψ. The global nodal displacement components are uuu, vvv, and ψ\psiψ. The local element vector is

uˉel={uˉ1vˉ1ψ1uˉ2vˉ2ψ2}\bar{\boldsymbol u}_{el}=\begin{Bmatrix}\bar u_1\\[3pt]\bar v_1\\[3pt]\psi_1\\[3pt]\bar u_2\\[3pt]\bar v_2\\[3pt]\psi_2\end{Bmatrix}uˉel​=⎩⎨⎧​uˉ1​vˉ1​ψ1​uˉ2​vˉ2​ψ2​​⎭⎬⎫​

The rotation angle of the normal, the rotation angle of the cross-section, and the shear angle have the following expressions:

φ=dvˉdxˉ,ψ=φ−β,β=TGA0\varphi=\frac{d\bar v}{d\bar x},\qquad \psi=\varphi-\beta,\qquad \beta=\frac{T}{GA_0}φ=dxˉdvˉ​,ψ=φ−β,β=GA0​T​

The rotation of the cross-section is related to the bending moment by

dψdxˉ=MEI\frac{d\psi}{d\bar x}=\frac{M}{EI}dxˉdψ​=EIM​

The nodal angular degree of freedom is ψ\psiψ, the rotation of the cross-section, not φ\varphiφ, the rotation of the normal.

The Euler–Bernoulli model is recovered when β=0\beta=0β=0, so that φ=ψ\varphi=\psiφ=ψ.

MATLAB programs

The package contains five commented files. gen.m defines the model; deriv.m evaluates the generalized strain rows; stiff.m uses two-point Gauss integration and assembles the structure; stress.m recovers N, T, and M; and main.m runs the analysis and plots the results.

stiff.mTwo-point Gauss integration
%*** stiff.m ***
for ig = 1:2
    xc = 1/2*(1 + xg(ig));
    deriv
    kel = kel + L/2*(ea*ep1*ep1' + ga*be1*be1' + ei*ka1*ka1');
end
K(ip,ip) = K(ip,ip) + R'*kel*R;

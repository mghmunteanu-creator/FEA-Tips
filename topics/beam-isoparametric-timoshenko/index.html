01

Model and interpolation

The element is straight and prismatic, with two nodes and the local degrees of freedom uˉ,vˉ,ψ\bar u,\bar v,\psiuˉ,vˉ,ψ at each node. The analysis is performed in the global xyxyxy plane.

The notation is retained exactly: φ\varphiφ is the rotation of the normal, ψ\psiψ is the rotation of the cross-section, and

β=φ−ψ\beta=\varphi-\psiβ=φ−ψ

With the natural coordinate −1≤s≤1-1\leq s\leq1−1≤s≤1, the linear shape functions and coordinate interpolation are

04

Shear locking and correction

If we modify the above last expression like this

kˉelC=L(EABϵTBϵ+γGA0BβTBβ+EIBκTBκ)s=0\bar{\boldsymbol k}_{el}^{C}=L\left(EA\boldsymbol B_{\epsilon}^{T}\boldsymbol B_{\epsilon}+\gamma GA_0\boldsymbol B_{\beta}^{T}\boldsymbol B_{\beta}+EI\boldsymbol B_{\kappa}^{T}\boldsymbol B_{\kappa}\right)_{s=0}kˉelC​=L(EABϵT​Bϵ​+γGA0​BβT​Bβ​+EIBκT​Bκ​)s=0​
m=12EIL2GA0,γ=m1+mm=\frac{12EI}{L^2GA_0},\qquad \gamma=\frac{m}{1+m}m=L2GA0​12EI​,γ=1+mm​

The factor γ\gammaγ scales the one-point shear contribution according to the bending-to-shear stiffness ratio. It is a dimensionless correction; no additional derivation is required for its use here.

Using one-point Gauss integration together with the correction factor γ\gammaγ, the stiffness matrix becomes identical to the expression obtained for the Timoshenko beam element presented in Section 5.2.

05

Numerical examples

Consider a cantilever with L=100 mmL=100\ \mathrm{mm}L=100 mm, E=2×105 MPaE=2\times10^5\ \mathrm{MPa}E=2×105 MPa, G=E/2.5G=E/2.5G=E/2.5, rectangular cross-section 5 mm×20 mm5\ \mathrm{mm}\times20\ \mathrm{mm}5 mm×20 mm, Pv=104 NP_v=10^4\ \mathrm{N}Pv​=104 N, and H=35 NH=35\ \mathrm{N}H=35 N. The exact-integration element converges slowly because of shear locking; the reduced-integration form and the corrected form converge much more rapidly.

For pure bending with C=106 N mmC=10^6\ \mathrm{N\,mm}C=106 Nmm, three exactly integrated elements give vmax=3.89 mmv_{max}=3.89\ \mathrm{mm}vmax​=3.89 mm instead of CL2/(2EI)=7.5 mmCL^2/(2EI)=7.5\ \mathrm{mm}CL2/(2EI)=7.5 mm. The discrepancy is caused by spurious shear force. The one-point element gives the correct pure-bending displacement and zero shear force.

06

MATLAB programs

The package contains four commented files. gen.m defines the model; stiff.m assembles the corrected one-point element; stress.m recovers N, T, and M; and main.m runs the analysis and plots the results.

stiff.mCorrected one-point integration
%*** stiff.m ***
gamma = 12*ei/(L^2*ga + 12*ei);
gac = gamma*ga;
% One-point shear contribution with correction
K(ip,ip) = K(ip,ip) + R'*kel*R;
MATLAB compatibility

The package uses MATLAB R2017b-compatible syntax and was checked with MATLAB R2026a. No additional toolbox is required.

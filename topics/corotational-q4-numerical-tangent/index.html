Sections 16.1 and 16.2 use different approximations of the element tangent stiffness matrix. In the present section, the tangent matrix is obtained directly by central numerical differentiation of the element internal nodal force vector:

kel=∂fel∂uel\boldsymbol{k}_{el}=\frac{\partial\boldsymbol{f}_{el}}{\partial\boldsymbol{u}_{el}}kel​=∂uel​∂fel​​

The nodal displacement vector of the 4-node quadrilateral element is:

uel=(u1  v1  u2  v2  u3  v3  u4  v4)T\boldsymbol{u}_{el}=\left(u_1\;v_1\;u_2\;v_2\;u_3\;v_3\;u_4\;v_4\right)^Tuel​=(u1​v1​u2​v2​u3​v3​u4​v4​)T

02

Central finite differences

Let δ\deltaδ denote the numerical differentiation perturbation. For each element degree of freedom iii, two perturbed displacement vectors are introduced:

uel+=uel+δei\boldsymbol{u}_{el}^{+}=\boldsymbol{u}_{el}+\delta\boldsymbol{e}_iuel+​=uel​+δei​
uel−=uel−δei\boldsymbol{u}_{el}^{-}=\boldsymbol{u}_{el}-\delta\boldsymbol{e}_iuel−​=uel​−δei​

Here, ei\boldsymbol{e}_iei​ is the eight-component unit vector associated with degree of freedom iii: its iiith component is one and all other components are zero. Column iii of the element tangent matrix is approximated by:

kel(:,i)≈fel ⁣(uel+δei)−fel ⁣(uel−δei)2δ\boxed{\boldsymbol{k}_{el}(:,i)\approx\frac{\boldsymbol{f}_{el}\!\left(\boldsymbol{u}_{el}+\delta\boldsymbol{e}_i\right)-\boldsymbol{f}_{el}\!\left(\boldsymbol{u}_{el}-\delta\boldsymbol{e}_i\right)}{2\delta}}kel​(:,i)≈2δfel​(uel​+δei​)−fel​(uel​−δei​)​​

For example, for i=3i=3i=3:

e3=(0  0  1  0  0  0  0  0)T\boldsymbol{e}_3=\left(0\;0\;1\;0\;0\;0\;0\;0\right)^Te3​=(00100000)T

The MATLAB variable corresponding to δ\deltaδ is dd.

03

Element internal-force reevaluation

For each +δ+\delta+δ or −δ-\delta−δ perturbation, the 8×18\times18×1 element internal nodal force vector fel\boldsymbol{f}_{el}fel​ is recomputed.

The rot routine is called again for every perturbation. It computes the rigid-body rotation and the corotated nodal-displacement vector:

u~el=(I2−R)xel0+uel\widetilde{\boldsymbol{u}}_{el}=(\boldsymbol{I}_2-\boldsymbol{R})\boldsymbol{x}_{el0}+\boldsymbol{u}_{el}uel​=(I2​−R)xel0​+uel​

where xel0\boldsymbol{x}_{el0}xel0​ contains the nodal coordinates of the initial element configuration and uel\boldsymbol{u}_{el}uel​ contains the current nodal displacements.

Consequently, each perturbed state includes the updated rigid-body rotation, corotational configuration, corotated nodal displacements, Jacobian matrix, strain-displacement matrix, strains, stresses, current thickness, and internal nodal force vector. The calculation follows the sequence:

uel⟶R⟶u~el⟶J,B⟶ε⟶σ⟶fel\boldsymbol{u}_{el}\longrightarrow\boldsymbol{R}\longrightarrow\widetilde{\boldsymbol{u}}_{el}\longrightarrow\boldsymbol{J},\boldsymbol{B}\longrightarrow\boldsymbol{\varepsilon}\longrightarrow\boldsymbol{\sigma}\longrightarrow\boldsymbol{f}_{el}uel​⟶R⟶uel​⟶J,B⟶ε⟶σ⟶fel​

04

MATLAB implementation

The calculation of the element internal nodal force vector is placed in the separate subprogram fel_el. Therefore, the same sequence is used for the actual state and for the +δ+\delta+δ and −δ-\delta−δ states without repeating the code.

No analytical differentiation subprogram such as deltaB, used in Section 16.2, is required.

In the following excerpt, nod contains the four node numbers of the current element; u and v are the global nodal-displacement vectors in the xxx- and yyy-directions; and inod is the local node position associated with the perturbed degree of freedom:

dd=1e-5;                    % numerical differentiation perturbation
for ie=1:nel
    nod=elem(ie,:);
    istore=1;
    fel_el
    fel=felt;

    istore=0;
    for ipert=1:8
        inod=ceil(ipert/2);
        if rem(ipert,2)==1
            u(nod(inod))=u(nod(inod))+dd;
        else
            v(nod(inod))=v(nod(inod))+dd;
        end
        fel_el
        felp=felt;

        if rem(ipert,2)==1
            u(nod(inod))=u(nod(inod))-2*dd;
        else
            v(nod(inod))=v(nod(inod))-2*dd;
        end
        fel_el
        felm=felt;

        if rem(ipert,2)==1
            u(nod(inod))=u(nod(inod))+dd;
        else
            v(nod(inod))=v(nod(inod))+dd;
        end
        kel(:,ipert)=(felp-felm)/(2*dd);
    end
end

The internal-force subprogram evaluates the complete element sequence:

%*** fel_el ***
rot
felt=zeros(8,1);
for j=1:4
    s=st(1,j);
    t=st(2,j);
    H=[(1+t)/4  -(1+t)/4  -(1-t)/4   (1-t)/4
       (1+s)/4   (1-s)/4  -(1-s)/4  -(1+s)/4];
    J=H*[xdel ydel];
    detJ=abs(det(J));
    J1=inv(J);
    b=J1*H;
    B=[b(1,1)       0    b(1,2)       0    b(1,3)       0    b(1,4)       0
           0    b(2,1)       0    b(2,2)       0    b(2,3)       0    b(2,4)
       b(2,1)   b(1,1)   b(2,2)   b(1,2)   b(2,3)   b(1,3)   b(2,4)   b(1,4)];
    strn=B*sel;
    sg=DHooke*strn;
    th1=(1-nu/(1-nu)*(strn(1)+strn(2)))*th;
    felt=felt+th1*(B'*sg)*detJ;
end

06

Symmetry criterion

The relative asymmetry of an element tangent matrix is measured by:

ηsym=∥kel−kelT∥F∥kel∥F\boxed{\eta_{\mathrm{sym}}=\frac{\left\|\boldsymbol{k}_{el}-\boldsymbol{k}_{el}^{T}\right\|_F}{\left\|\boldsymbol{k}_{el}\right\|_F}}ηsym​=∥kel​∥F​​kel​−kelT​​F​​​

Here, the Frobenius norm of a matrix A\boldsymbol{A}A is:

∥A∥F=∑i∑jaij2\left\|\boldsymbol{A}\right\|_F=\sqrt{\sum_i\sum_j a_{ij}^{2}}∥A∥F​=i∑​j∑​aij2​​

The symmetry indicator therefore measures the relative magnitude of the antisymmetric part of kel\boldsymbol{k}_{el}kel​. A value close to zero indicates an approximately symmetric matrix.

For Section 16.3, the mean value is:

η‾sym≈1.31×10−2\overline{\eta}_{\mathrm{sym}}\approx1.31\times10^{-2}η​sym​≈1.31×10−2

No artificial symmetrization is used. Artificial symmetrization was tested. It made convergence somewhat slower, and for δ=10−10\delta=10^{-10}δ=10−10 the symmetrized tangent no longer converged.

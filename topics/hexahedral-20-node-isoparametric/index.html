Element and hypotheses

StrainSmall
DisplacementSmall
MaterialLinear elastic

The formulation closely follows Section 25.1. Only the differences associated with the quadratic 20-node interpolation and the 3×3×33\times3\times33×3×3 Gauss integration are presented here.

The HEX20 element has 20 nodes, three displacement DOFs per node and 60 element displacement DOFs. The stiffness integration uses 27 Gauss points.

uel∈R60×1,kel∈R60×60.\boldsymbol{u}_{el}\in\mathbb R^{60\times1},\qquad\boldsymbol{k}_{el}\in\mathbb R^{60\times60}.uel​∈R60×1,kel​∈R60×60.

06

MATLAB program

For given natural coordinates s,t,rs,t,rs,t,r, the shape20 subprogram evaluates the HEX20 interpolation functions N\boldsymbol NN and their derivatives with respect to the natural coordinates. These derivatives are then used to construct the Jacobian J\boldsymbol JJ and the strain-displacement matrix B\boldsymbol BB.

The mesh for the example is generated by gen. Run main.m to generate the mesh, solve the linear problem with brick3d_20, and display the displacement and stress maps.

07

Example

The same cantilever beam as in Section 25.1 is used, with the same geometry, material, loading and boundary conditions. Its length is 200 mm200\,\mathrm{mm}200mm, its cross-section is 50×40 mm50\times40\,\mathrm{mm}50×40mm, E=2×105 MPaE=2\times10^5\,\mathrm{MPa}E=2×105MPa, ν=0.3\nu=0.3ν=0.3 and the vertical end load is 8000 N8000\,\mathrm N8000N.

The 24×9×624\times9\times624×9×6 HEX20 mesh contains 1 296 elements, 6 505 nodes and 19 515 displacement DOFs. This is considerably coarser than the HEX8 discretization in Section 25.1, which uses 11 520 elements and 13 481 nodes.

The maximum vertical displacement magnitude and the near-zero opposite extreme are:

∣w∣max⁡=0.41377 mm,w≈2.17×10−4 mm.|w|_{\max}=0.41377\,\mathrm{mm},\qquad w\approx2.17\times10^{-4}\,\mathrm{mm}.∣w∣max​=0.41377mm,w≈2.17×10−4mm.

The actual negative displacement extreme is wmin⁡=−0.41377 mmw_{\min}=-0.41377\,\mathrm{mm}wmin​=−0.41377mm.

The axial-stress extrema, rounded to two decimal places, are:

σx,max⁡=119.07 MPa,σx,min⁡=−119.07 MPa.\sigma_{x,\max}=119.07\,\mathrm{MPa},\qquad\sigma_{x,\min}=-119.07\,\mathrm{MPa}.σx,max​=119.07MPa,σx,min​=−119.07MPa.

The beam-theory reference values discussed in Section 25.1 are:

∣w∣max⁡=0.4125 mm,σmax⁡=120 MPa.|w|_{\max}=0.4125\,\mathrm{mm},\qquad\sigma_{\max}=120\,\mathrm{MPa}.∣w∣max​=0.4125mm,σmax​=120MPa.

The relative differences are approximately 0.31%0.31\%0.31% for the displacement and 0.78%0.78\%0.78% for the axial stress. These results confirm the very good accuracy of the HEX20 element, despite the coarser discretization.

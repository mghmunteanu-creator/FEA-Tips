01

Introduction

brick3d_fast is the vectorized version of the brick3d program from Section 25.1. The approach is very similar to plane2d_fast in Section 9.5, following the fast implementation approach also used in Section 9.2.

Multidimensional arrays are used to process simultaneously the matrices associated with all elements and Gauss points.

02

Vectorized formulation

For the HEX8 element, the strain–displacement matrix and the three-dimensional constitutive matrix have dimensions:

B∈R6×24,D∈R6×6.\boldsymbol{B}\in\mathbb{R}^{6\times24},\qquad\boldsymbol{D}\in\mathbb{R}^{6\times6}.B∈R6×24,D∈R6×6.

Jacobians, inverse Jacobians, strain–displacement matrices and constitutive matrices are evaluated in vectorized form for all elements and their eight Gauss points. The matrix products are:

DB,BTDB.\boldsymbol{D}\boldsymbol{B},\qquad\boldsymbol{B}^{T}\boldsymbol{D}\boldsymbol{B}.DB,BTDB.

multiprod performs multiple matrix products in multidimensional arrays. Global assembly is also vectorized using MATLAB sparse, avoiding element-by-element assembly loops.

03

Linear system

After assembly and imposition of the boundary conditions, the linear system is:

KS=F.\boldsymbol{K}\boldsymbol{S}=\boldsymbol{F}.KS=F.

K\boldsymbol{K}K is the global stiffness matrix, F\boldsymbol{F}F the load vector and S\boldsymbol{S}S the unknown nodal displacement vector. The direct MATLAB solution is:

Direct solution
S = K\F;

04

Benchmark example

The same cantilever example as in Section 25.1 is used. The coarse mesh has 60×16×1260\times16\times1260×16×12 elements: 11 520 elements, 13 481 nodes and 40 443 equations. The fine mesh has 90×24×1890\times24\times1890×24×18 elements: 38 880 elements, 43 225 nodes and 129 675 equations.

05

Preconditioned conjugate gradient method

For large linear-elastic FE systems, after appropriate boundary conditions are imposed, the stiffness matrix is sparse, symmetric and positive definite, so the preconditioned conjugate gradient method (PCG) is well suited. Preconditioning improves conditioning and reduces the number of iterations [1].

The MATLAB implementation uses incomplete Cholesky factorization followed by pcg [2]:

Incomplete Cholesky and PCG
opts.type    = 'ict';
opts.droptol = 1e-3;

L = ichol(K,opts);
[S,flag,relres,iter] = pcg(K,F,1e-6,200,L,L');

ict selects incomplete Cholesky factorization with threshold dropping; droptol = 1e-3 controls the dropping tolerance. L\boldsymbol{L}L and LT\boldsymbol{L}^{T}LT are used as the two preconditioner factors for pcg.

The incomplete Cholesky factorization provides a sparse approximation of the stiffness matrix:

K≈LLT.\boldsymbol{K}\approx\boldsymbol{L}\boldsymbol{L}^{T}.K≈LLT.

The factors L\boldsymbol{L}L and LT\boldsymbol{L}^{T}LT are then used as preconditioners in the PCG algorithm. In simplified form, the preconditioned system may be written as:

(LLT)−1K S=(LLT)−1F.(\boldsymbol{L}\boldsymbol{L}^{T})^{-1}\boldsymbol{K}\,\boldsymbol{S}=(\boldsymbol{L}\boldsymbol{L}^{T})^{-1}\boldsymbol{F}.(LLT)−1KS=(LLT)−1F.

Since LLT\boldsymbol{L}\boldsymbol{L}^{T}LLT approximates K\boldsymbol{K}K, the preconditioned system is better conditioned and PCG converges more rapidly.

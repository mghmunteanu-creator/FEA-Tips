Timoshenko beam model.

Straight, prismatic, two-node isoparametric beam element. The element formulation follows the notation introduced in Section 23.3.

In the Updated Lagrangian formulation, the equilibrium configuration obtained at the end of load step iii becomes the reference configuration for load step i+1i+1i+1. Therefore, the incremental displacements and stresses at the current load step are evaluated with respect to the previously deformed configuration.

The present formulation extends to 3D the Updated Lagrangian procedure introduced for the 2D case in Section 8.2.

The generalized strain vector is expressed in the local reference frame, using the notation introduced in Section 23.3.

ε={ε0βyˉβzˉκxˉκyˉκzˉ}.\boldsymbol{\varepsilon}=\begin{Bmatrix}\varepsilon_0\\\beta_{\bar y}\\\beta_{\bar z}\\\kappa_{\bar x}\\\kappa_{\bar y}\\\kappa_{\bar z}\end{Bmatrix}.ε=⎩⎨⎧​ε0​βyˉ​​βzˉ​κxˉ​κyˉ​​κzˉ​​⎭⎬⎫​.

The element nodal displacement vector in the local reference frame is:

u‾el={uˉ1vˉ1wˉ1ψxˉ1ψyˉ1ψzˉ1uˉ2vˉ2wˉ2ψxˉ2ψyˉ2ψzˉ2}T.\overline{\boldsymbol u}_{el}=\begin{Bmatrix}\bar u_1&\bar v_1&\bar w_1&\psi_{\bar x1}&\psi_{\bar y1}&\psi_{\bar z1}&\bar u_2&\bar v_2&\bar w_2&\psi_{\bar x2}&\psi_{\bar y2}&\psi_{\bar z2}\end{Bmatrix}^{T}.uel​={uˉ1​​vˉ1​​wˉ1​​ψxˉ1​​ψyˉ​1​​ψzˉ1​​uˉ2​​vˉ2​​wˉ2​​ψxˉ2​​ψyˉ​2​​ψzˉ2​​}T.

For each load step, the element equations are written in the current local reference frame of the straight two-node beam element.

Curvatures

In the present formulation, the curvatures are approximated by retaining the first-order terms:

κxˉ=ψxˉ2−ψxˉ1L\boxed{\kappa_{\bar x}=\frac{\psi_{\bar x2}-\psi_{\bar x1}}{L}}κxˉ​=Lψxˉ2​−ψxˉ1​​​
κyˉ=ψyˉ2−ψyˉ1L\boxed{\kappa_{\bar y}=\frac{\psi_{\bar y2}-\psi_{\bar y1}}{L}}κyˉ​​=Lψyˉ​2​−ψyˉ​1​​​
κzˉ=ψzˉ2−ψzˉ1L.\boxed{\kappa_{\bar z}=\frac{\psi_{\bar z2}-\psi_{\bar z1}}{L}.}κzˉ​=Lψzˉ2​−ψzˉ1​​.​

The second-order terms of the curvature expressions are neglected here. Their complete expressions and corresponding derivatives are presented separately in Addendum 24a.

This keeps the main development focused on the practical Updated Lagrangian algorithm, while the more complete curvature expressions can be consulted when required.

04

Updated Lagrangian procedure

The MATLAB implementation follows closely the 2D Updated Lagrangian algorithm presented in Section 8.2.

At each load step:

  1. the equilibrium equations are solved for the incremental nodal displacements;
  2. the nodal coordinates are updated;
  3. the current element lengths are recomputed;
  4. the element local reference frames are updated;
  5. the auxiliary third nodes used to define the principal plane of each 3D beam element are updated;
  6. the resulting configuration becomes the reference configuration for the next load step.

After updating the nodal coordinates,

x←x+Δu,y←y+Δv,z←z+Δw,x\leftarrow x+\Delta u,\qquad y\leftarrow y+\Delta v,\qquad z\leftarrow z+\Delta w,x←x+Δu,y←y+Δv,z←z+Δw,

the current length of every element is recalculated as:

Lt=(x2−x1)2+(y2−y1)2+(z2−z1)2.\boxed{L_t=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2+(z_2-z_1)^2}.}Lt​=(x2​−x1​)2+(y2​−y1​)2+(z2​−z1​)2​.​

This explicit update is used in the subprogram updt.

Update of the local reference frame

06

MATLAB program

The MATLAB implementation for the 3D Updated Lagrangian formulation follows the same general structure as the 2D program presented in Section 8.2.

The main subprograms are:

  • gen_ex2.m — Example 2 input data and mesh generation;
  • stiff — assembly of the tangent stiffness matrix and internal force vector;
  • deriv — first and second derivatives of the generalized strains;
  • updt — update of nodal coordinates, element lengths and local reference frames.

The exact axial strain is used directly in the numerical calculations, while the simplified derivative expressions described above are used in the tangent formulation.

The MATLAB package includes both deriv.m and deriv_corrected.m. The routine deriv_corrected.m implements the complete curvature expressions presented in Addendum 24a.
